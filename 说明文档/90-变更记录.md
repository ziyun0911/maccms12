### 3.3 `app/extra/maccms.php` 顶层分区一次性重排

原 `app/extra/README.md` 第二节记录的评估结论（**不做目录级分层，只做分类说明**）与一次性重排动作，搬到这里存档：

- 结论：配置加载是非递归 `glob()`（[app/common.php:14-28](file:///D:/wwwroot/maccms/maccms12/app/common.php#L14)），把文件挪进子目录等于不加载，

- 动作：把当时 23 个顶层键按「🖥️ 服务器 / ⚙️ 运营 / 🔒 系统级」重排物理顺序，**只调顺序不改值**。做法是一次性脚本：
  `include` 原文件 → 断言新序与原 `array_keys` 是同一组键 → 按新序组装、值直接引用 → 逐键 `===` 严格比较 → 备份原文件 →
  用与 `mac_arr2file()` 相同的 `var_export` 格式写盘 → 写盘后重新 `include` 再逐键比较一次，任一步失败就用备份还原。
- 现状（2026-10-27 复核）：文件已长成 29 个顶层键，前三段顺序仍在，后 6 个键（`ai_search` / `trusted_proxies` / `analytics` / `ai_content` / `monitor` / `push`）

  符合 `array_merge` 的行为，**不是重排失效**；要归位得再跑一次同款脚本。逐段清单见 [app/extra/README.md §5](file:///D:/wwwroot/maccms/maccms12/app/extra/README.md)。
