# 多语言手册

本手册讲清 maccms12 的**四套彼此独立的语言机制**：怎么开、改哪里、生效范围到哪、以及为什么改了却不变化。
每条结论都标了代码位置，可直接打开核对；文件路径均相对站点根目录（`D:/wwwroot/maccms/maccms12`）。

> 最容易混淆的一点：**界面语言**（后台/提示文案）和**内容语言**（同一部影片给不同访客显示不同名称/简介）是两套东西，
> 配置键、存储、切换方式都不同。第三、四层（`mac_tpl_text` 静态短语、`strings_*.properties` 前台短语包）是给模板里
> 写死的中文短语兜底用的，不属于数据库内容。

## 2. 语言注册表：加一门语言先要做的事

系统不认识「语言清单」这种配置文件——**`app/lang/` 下每一个 `.php` 就是一门语言**，按文件名当语言代码。
注册表由 [mac_lang_registry()](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4010) 在首次调用时用 `glob('app/lang/*.php')` 生成并静态缓存（文件名含 `.bak` 的会被跳过，[app/common.php:4020](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4020)）。

每个语言文件**前 4096 字节**里要有这几个元字段，它们是被正则从文件头“读文本”拿到的（[mac_lang_meta_read](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4049)，格式必须是 `'键' => '值'`），不是走 `include`：

| 键 | 作用 | 缺失时 |
|---|---|---|
| `lang_name` | 语言自称名（下拉框/切换器显示） | 用大写语言代码 |
| `lang_sort` | 排序（小在前） | `100 + 字母序下标` |
| `lang_flag` | emoji 国旗，图片旗标不可用时的回退（[app/common.php:4213](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4213)） | 空 |
| `lang_dir` | `ltr`/`rtl` | `ltr` |
| `lang_ui` | **第④层短语包的后缀**，决定读 `strings_{ui}.properties` | 该语言没有短语包 |
| `lang_legacy` | 旧版两字母代码（切换器 `data-flag-code`） | 语言代码前两位 |
| `lang_flag_png` | 旗标图片名，逗号分隔多个候选，按序取第一个存在的 | 无图片旗标 |

当前随包的 6 门语言（`ls app/lang/`）：

| 代码 | 名称 | sort | ui | 旗标图片候选 |
|---|---|---|---|---|
| `zh-cn` | 简体中文 | 10 | `zh` | `lang-zh` |
| `zh-tw` | 繁體中文 | 20 | `zh-tw` | `lang-tw,lang-zh-tw` |
| `en-us` | English | 30 | `en` | `lang-en,lang-us` |
| `ja-jp` | 日本語 | 40 | `ja` | `lang-ja,lang-jp` |
| `ko-kr` | 한국어 | 50 | `ko` | `lang-ko` |
| `ru-ru` | Русский | 60 | `ru` | `lang-ru` |

> **实测坑**：`template/default/images/la/` 里只有 `lang-zh.png`、`lang-en.png`、`lang-us.png` 三张旗标
> （[mac_front_lang_list](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4203) 逐个 `is_file` 探测）。
> 所以 `zh-tw / ja-jp / ko-kr / ru-ru` 的 `flag` 字段为空，前台切换器**自动回退成 emoji**（模板已处理，
> [template/default/html/widget/head_block_pc.html:113-117](file:///D:/wwwroot/maccms/maccms12/template/default/html/widget/head_block_pc.html#L113)）。这不是 bug。

新增一门语言的完整动作：
1. 复制一份 `app/lang/zh-cn.php` 改名成 `xx-yy.php`，改掉头部 7 个元字段（保持在前 4096 字节内、单引号写法）。
2. 后台「网站参数 → 前台内容语言」勾选 `xx-yy`（写进 `app.content_lang_list`），必要时把默认语言也换掉。
3. 想要第④层生效，补 `template/default/asset/language/strings_{lang_ui}.properties`；不补则该语言前台短语回落到模板里写死的中文。
4. 想要图片旗标，放 `template/default/images/la/{lang_flag_png 候选名}.png`。

界面语言包本身：**建议不改公共包**，改文案请在 `app/{模块}/lang/{语言}.php` 放同名 key——模块包会在公共包之后
`Lang::load()` 覆盖（[app/common/controller/All.php:52-55](file:///D:/wwwroot/maccms/maccms12/app/common/controller/All.php#L52)）。
注意现实状态：模块语言包只有 `app/{admin,api,index,install}/lang/zh-cn.php` 四个文件，其它语言在模块层没有覆盖，
未命中的 key 会原样显示 key 名。

## 3. ① 界面语言（后台与提示文案）

- 决定值：`app.lang`。安装器写入，后台可改：`admin.php/system/configlang?lang=xx`，
  只接受注册表里的代码，落盘到 `app/extra/maccms.php`（[app/admin/controller/System.php:2295-2311](file:///D:/wwwroot/maccms/maccms12/app/admin/controller/System.php#L2295)）。
- 生效链路：请求开始 → 中间件把 `app.lang` 同步给框架（`Config default_lang` + `Lang::setLangSet`，
  [Init.php:139-143](file:///D:/wwwroot/maccms/maccms12/app/common/middleware/Init.php#L139)）→ 控制器基类再 `switchLangSet` 并加载
  `app/lang/{lang}.php`（[All.php:41-56](file:///D:/wwwroot/maccms/maccms12/app/common/controller/All.php#L41)）。
- 与内容语言**互不影响**：把界面切成 `en-us` 不会让前台内容变英文；反之亦然。

### 4.3 访客语言怎么定下来

`app/index/controller/Base.php` 构造时调用 [init_content_lang()](file:///D:/wwwroot/maccms/maccms12/app/index/controller/Base.php#L23)，
API 模块同样在 [app/api/controller/Base.php:13](file:///D:/wwwroot/maccms/maccms12/app/api/controller/Base.php#L13)。判定顺序在
[mac_get_content_lang()](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4224)：

1. `?lang=xx-yy`（GET，优先级最高）
2. Cookie `mac_content_lang`
3. `Accept-Language` 的第一个子标签
4. `app.content_lang_default`

候选值必须**命中 `app.content_lang_list` 展开后的清单**，否则静默回退默认语言（[app/common.php:4247](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4247)）。
只有第 1 种情况会写 Cookie，有效期 30 天、路径 `/`（[app/common.php:4251-4256](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4251)）。

> 两个已知边界：
> - `content_lang_list` 为空时函数直接返回默认语言，**不写 Cookie**（[app/common.php:4228](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4228)）。
> - `Accept-Language: en` 这种两字母写法**不会**被扩展成 `en-us`（这里没有 `lang_legacy` 反查），会落回默认语言。
>   两字母兼容只在**前台切换器 JS** 里做（`normalize()`，[static/js/mac-theme-runtime.js:23-31](file:///D:/wwwroot/maccms/maccms12/static/js/mac-theme-runtime.js#L23)）。

启用清单的读法：`app.content_lang_list` 用 `|` 分隔，再和注册表代码取交集（[mac_content_lang_allow_list](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4178)）；
默认语言总被隐式包含在可切换集合里（保存配置的前端会把默认项强制勾上，[app/admin/view/system/config.html:1504-1508](file:///D:/wwwroot/maccms/maccms12/app/admin/view/system/config.html#L1504)）。

## 5. ③ 模板静态短语（`mac_tpl_text`）

模板里写死的中文短语（`电影`、`更多`、`换一换`、`VIP会员`、默认 SEO 标题等）由
[mac_tpl_text()](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4074) 按当前内容语言查一张 **34 条的静态映射表**
（[app/common.php:4085-4125](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4085)），命中就替换，不命中原样返回；当前语言 = 默认语言时整个函数直通。

用法（模板里）：`{:mac_tpl_text('更多')}`、`{:mac_tpl_text($vo['group_name'])}`。全站 25 个调用点，集中在
`template/default/html/module/index_theme_vars.html`、`user/*.html`、直播 API 与会员 API。

加一条短语：直接在 `$map` 里追加 `'中文' => ['zh-tw'=>..., 'en-us'=>..., ...]`；键必须与传入文本**逐字相等**（区分全角/空格）。
这是纯代码扩展点，没有后台界面。

## 6. ④ 前台短语包（`strings_{ui}.properties`）

- 文件：`template/default/asset/language/strings_{ui}.properties`，`ui` 取自语言包的 `lang_ui`
  （[app/common.php:4141](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4141)）。当前 6 个文件、每个 1351 个键，六种语言一一对应。
- 语法：`key=value` 一行一条，`#` / `!` 开头行与空行跳过，键值两端空白自动去掉（[app/common.php:4146-4158](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4146)）；同语言文件首次读取后进程内静态缓存。

## 7. 运维：改完不生效的排查顺序

| 症状 | 原因 | 处理 |
|---|---|---|
| 前台详情页切换语言后不变 | 内容语言由 `?lang=`/Cookie/`Accept-Language` 决定，Cookie 里还留着旧值 | 清 `mac_content_lang` Cookie，或带 `?lang=xx-yy` 访问一次 |
| **分类名/分类导航**改了库或改了译文后仍显示旧的 | 分类走 `type_list`/`type_tree` 核心缓存，键前缀是 `app.cache_flag`（[Type.php:403](file:///D:/wwwroot/maccms/maccms12/app/common/model/Type.php#L403)，flag 取自 [maccms.php:98](file:///D:/wwwroot/maccms/maccms12/app/extra/maccms.php#L98)） | 后台「清除缓存」，或直接删 `runtime/cache` 下 `{flag}_type_list`、`{flag}_{语言}_type_list` 等键；改 `cache_flag` 可一次性让全部核心缓存失效 |
| 列表标签（`{maccms:vod}`）里名称不变 | 列表标签本来就不做译文覆盖，且列表缓存键是查询条件哈希，写数据不会失效 | 见 `05-模板标签手册.md` §缓存；等 `cache_time` 过期或改 `cache_flag` |
| 整页缓存串语言 | 若曾手改过缓存 key 逻辑才会发生；原生 key 已带语言 | 确认 [All.php:153](file:///D:/wwwroot/maccms/maccms12/app/common/controller/All.php#L153) 未被改动 |
| 静态首页/WAP 首页没有多语言 | 生成静态在后台入口，语言恒为默认（`Make.php` 无 `content_lang` 逻辑） | 多语言站请用动态页 + 整页缓存；静态首页只服务默认语言 |
| `?lang=ja-jp` 后前台短语仍是中文 | 该语言 `lang_ui` 对应的 `strings_ja.properties` 缺键，或语言包头部没写 `lang_ui` | 补 properties；核对 `app/lang/ja-jp.php` 前 4096 字节内的 `'lang_ui' => 'ja'` |
| 切换器没有国旗 | 只有 3 张旗标 PNG | 属预期，自动用 emoji；要图片请放 `template/default/images/la/{候选名}.png` |
| 跨页签切换语言不同步 | `mac-theme-runtime.js` 监听的是 `storage`（localStorage）事件，而切换器写的是 **cookie**，该监听实际不会被触发（[static/js/mac-theme-runtime.js:48-57](file:///D:/wwwroot/maccms/maccms12/static/js/mac-theme-runtime.js#L48)） | 现状如此；刷新其它页签即可 |
| `mac_content_lang` 里有孤儿行（主记录已删） | 用 SQL 直删主表绕过级联删除 | 按 `content_type`+`content_id` 反查主表后删除孤儿；先备份（本机备份放 docroot 外的 `D:/wwwroot/maccms/_db_backup/`）。2026-10-26 已清过一次：删 165 行 `type` 孤儿译文 |

清理前定位孤儿的 SQL（只读，先看数量再删）：

```sql
SELECT cl.content_type, cl.content_id, cl.lang_code
FROM mac_content_lang cl
LEFT JOIN mac_type t ON t.type_id = cl.content_id
WHERE cl.content_type = 'type' AND t.type_id IS NULL;
```

## 8. 自动翻译（可选）

后台非默认语言字段旁的「自动翻译」按钮，只在 `mac_content_translate_available()` 为真时渲染
（[app/common.php:4290-4296](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4290)）。它有两条来源，任一可用即显示：

1. **内置翻译通道**：[app/common/util/Translate.php](file:///D:/wwwroot/maccms/maccms12/app/common/util/Translate.php)，支持 `baidu` / `tencent` / `deepl` / `openai` 四种，
   凭证配在 `app/extra/translate.php`（该文件被 gitignore，**不要提交、不要在文档里写值**）。`available()` 按渠道检查必填凭证键（[Translate.php:38-55](file:///D:/wwwroot/maccms/maccms12/app/common/util/Translate.php#L38)）；
   语言代码由 `mapLang()` 映射到各家写法（[Translate.php:57-79](file:///D:/wwwroot/maccms/maccms12/app/common/util/Translate.php#L57)），`deepl` 的 `zh-cn`/`zh-tw` 都归 `ZH`。
2. **插件钩子** `content_translate`：装了注册该钩子的插件即生效，约定见 [app/common.php:4298-4324](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4298)
   （入参 `text/from/to/context`，返回字符串表示已处理，返回 `null` 交给下一个）。

后台动作 `*/contentLangTranslate`（如 [app/admin/controller/Vod.php:605-615](file:///D:/wwwroot/maccms/maccms12/app/admin/controller/Vod.php#L605)）在调用前后受
**按管理员限流**：默认 40 次/分钟、600 次/小时（[mac_content_translate_rate_limit](file:///D:/wwwroot/maccms/maccms12/app/common.php#L4326)），
计数落在核心缓存；没有可用翻译通道时**不计数、直接放行**。两者都不可用时按钮不显示，全程手填也能用。

> 翻译请求走 cURL 且 `SSL_VERIFYPEER/HOST` 关闭（[Translate.php:220-221](file:///D:/wwwroot/maccms/maccms12/app/common/util/Translate.php#L220)、[:239-240](file:///D:/wwwroot/maccms/maccms12/app/common/util/Translate.php#L239)）。
> 这是**已知取舍**（老环境缺 CA 包），意味着译文通道不校验证书。生产环境请自行评估，别把敏感字段拿去翻译。
