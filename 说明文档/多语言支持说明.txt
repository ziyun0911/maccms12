========================================================================
maccms12（ThinkPHP 8）说明
========================================================================
本文档基于官方 maccms10「多语言支持说明」整理。maccms12 为 TP8 升级版，
语言包机制完全一致；仅目录结构随框架升级变化：application/ 已改为 app/。
界面语言包（界面文案）与「内容级多语言」（同一内容多语言展示，见同目录
《内容级多语言说明》）是两套独立机制，请注意区分。

========================================================================
v10版本增加了多语言的支持，方便更多全球用户使用，系统内所有显示和提示的信息完全由语言包控制。
系统默认内置了简体中文，繁体中文语言包，安装的时候选择切换您熟悉的语言即可在 安装、后台中完全显示对应的语言，所有模块提示信息也将显示对应语言。
后续还将内置或提供更多的语言包扩展，也欢迎大家友情提供。
建议不要修改公共语言包，如果想替换公共语言包里的内容，可以到对应的模块语言包下创建同样key的内容即可自动加载替换。

==语言包结构（maccms12 为 app/ 目录结构）==
│─app/
│ ├─lang/ 公共语言包
│ ├──zh-cn.php 简体中文
│ ├──zh-tw.php 繁体中文
│ ├──en-us.php 英文
│ ├──…
│ ├─admin/lang/ admin模块自定义语言包
│ ├──zh-cn.php
│ ├──zh-tw.php
│ ├─…
│ ├─api/lang/ api模块自定义语言包
│ ├──zh-cn.php
│ ├──zh-tw.php
│ ├─…
│ ├─install/lang/ 安装程序语言包
│ ├─index/lang/ 前台模块语言包
│ ├─…
等等…

==maccms12 语言包说明==
· 公共语言包位于 app/lang/，各模块语言包位于 app/{模块}/lang/。
· maccms12 实际随包提供 6 个公共语言包：zh-cn / zh-tw / en-us / ja-jp / ko-kr /
  ru-ru（上文「内置简体中文、繁体中文」是官方 v10 的说法，已不止两种）；
  模块语言包目前只有 app/{admin,api,index,install}/lang/zh-cn.php 四个，
  其它语言在这些模块下走公共包同名 key，不存在就显示 key 本身。
· 安装时可选择语言；后台可切换界面语言。
· 语言包为纯 PHP return 数组，key 与文案一一对应，模块语言包与公共语言包
  同 key 时以模块语言包优先（自动覆盖）。
