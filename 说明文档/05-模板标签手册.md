## 2. 语法骨架

```
{maccms:vod num="12" type="1" start="6" order="desc" by="hits_month" paging="yes" pageurl="vod/type"}
    <li>{$vo.vod_name} / {$vo.type.name} / {$key}</li>
{/maccms:vod}
```

### 2.1 三条底层规则（先记住，后面所有表都建立在这之上）

1. **`attr` 声明在运行时零作用**。框架只收集标签上**实际写出的**属性（`vendor/topthink/think-template/src/template/TagLib.php:237-240`），
   并且只对 `must` 键做必填校验——而 [Maccms.php:7-28](file:///D:/wwwroot/maccms/maccms12/app/common/taglib/Maccms.php#L7) **一个 `must` 都没声明**。
   ⇒ 属性写错、多写、漏写都不会报错；**唯一有效的判定是「模型 `listCacheData()` 里读不读这个键」**。
   例：`vod` 的声明里没有 `plot`/`wd`/`director`，但 `wd`、`director`、`plot` 确实生效（[Vod.php:150,155,173](file:///D:/wwwroot/maccms/maccms12/app/common/model/Vod.php#L150)）。
2. **`id=` 不是记录 ID**，它在标签库内被复用为 **volist 循环变量名**（默认 `vo`；[Maccms.php:87-92](file:///D:/wwwroot/maccms/maccms12/app/common/taglib/Maccms.php#L87) 等每个标签同构）。
   按 ID 取数请用 **`ids=`**（[Vod.php:297-301](file:///D:/wwwroot/maccms/maccms12/app/common/model/Vod.php#L297)）。模型层从不读 `$lp['id']`。
3. **返回契约固定**。列表类标签的模型返回 `['code','msg','page','pagecount','limit','total','list','pageurl','half']`
   （[Vod.php:86,130](file:///D:/wwwroot/maccms/maccms12/app/common/model/Vod.php#L86)、[:635-636](file:///D:/wwwroot/maccms/maccms12/app/common/model/Vod.php#L635)）。
   模板里可见：`$__LIST__`（整个数组，循环入口 `$__LIST__['list']`）、`$__PAGING__`（仅 `paging="yes"` 时生成，[Maccms.php:397](file:///D:/wwwroot/maccms/maccms12/app/common/taglib/Maccms.php#L397) 等 9 处）、
   以及 `id=`/`key=` 指定的循环变量与下标名。

`$__PAGING__` 的可用键见公共分页片段：`page_url / page_sp / page_total / page_current / page_prev / page_num_min …`
（[template/default/html/public/paging.html:3-14](file:///D:/wwwroot/maccms/maccms12/template/default/html/public/paging.html#L3)）。

### 3.1 七个「扩展字典」标签的数据来源

`area/lang/class/year/version/state` 读的是 `app/extra/maccms.php` 里的 `app.vod_extend_*` 配置串（逗号分隔），
`letter` 是**硬编码** `A..Z,0-9`（[Extend.php:369](file:///D:/wwwroot/maccms/maccms12/app/common/model/Extend.php#L369)）。共性：

- 后台「网站参数」里改这些扩展分类**即时生效**（无缓存）。
- `order` 只区分 `desc`（触发 `array_reverse`），其它值等同正序（[Extend.php:161-163](file:///D:/wwwroot/maccms/maccms12/app/common/model/Extend.php#L161)）。
- 返回行键是 `area_name / lang_name / class_name / year_name / version_name / state_name / letter_name`。
- `tid` 是唯一额外键：`tid>0` 时改用该分类的 `type_extend.area` 等字段作为字典来源（[Extend.php:145-151](file:///D:/wwwroot/maccms/maccms12/app/common/model/Extend.php#L145)）。
- `start>1` 才做偏移（[:156-158](file:///D:/wwwroot/maccms/maccms12/app/common/model/Extend.php#L156)），与 `vod` 的 `start>0` 判定**不一致**——`start="1"` 在两类标签上行为不同。
- 固定 `page=1`，不支持分页（[:174](file:///D:/wwwroot/maccms/maccms12/app/common/model/Extend.php#L174)）。

## 6. 标签缓存

三层，都会造成「改了数据页面不变」：

| 层 | 键 | TTL | 说明 |
|---|---|---|---|
| 列表标签 | `cache_flag _ md5('{命名空间}_listcache_' + 查询条件 + order + page + num + start + pageurl)` | `cachetime=`，留空取 `app.cache_time` | 命名空间按标签：`vod_/art_/manga_/actor_/role_/website_/topic_/comment_/gbook_/link_`；`type` 的键**含语言**（[Type.php:200](file:///D:/wwwroot/maccms/maccms12/app/common/model/Type.php#L200)）。**键里没有数据版本 → 写数据不会失效** |
| 分类字典 | `cache_flag_type_list` / `_type_tree`（+ 每语言变体） | 由 TTL 配置 | `getCache` 未命中自动回源重建（[Type.php:385-407](file:///D:/wwwroot/maccms/maccms12/app/common/model/Type.php#L385)） |
| 整页 HTML | 含 `cache_flag` + 内容语言 + 模板 + 参数 | `app.cache_time_page` | 仅 `app.cache_page=1` 时生效 |

- 总开关 `app.cache_core`（`'0'` = 不读不写，直查库）。
- 单个标签想立刻见效：写 `cachetime="0"`（走 `app.cache_time` 回落，实测仍会缓存）或直接关 `cache_core`；**唯一确定的一次性失效是改 `cache_flag`**。
- 后台「清除缓存」清全部：见 `07-定时任务与运维手册.md` §7.3。
- 七个扩展字典标签**没有缓存**（全程无 `Cache::` 调用）。
- 改 `.html` 不生效属于另一套：模板编译缓存 `runtime/temp/`，清它即可。

## 7. 常用片段写法

```html
{include file="public/head"}
{include file="public/paging"}
{include file="ads/ads_icon1" ads_icon1_marquee="0"}
{include file="widget/vod_box" /}
```

- `file` 路径相对 `template/default/html/`；`ads/...` 对应 `template/default/ads/`。
- **支持向片段传参**（上面 `ads_icon1_marquee="0"` 是实例），片段内直接当变量用。
- 内容链接用 `{:mac_url(...)}` 族（[app/common.php:2335](file:///D:/wwwroot/maccms/maccms12/app/common.php#L2335) 起），ajax/用户态端点用 TP 原生 `{:url(...)}`；当前模板两种写法分别是 263 处 / 164 处。URL 形态与开关见 `04-前台模板与静态化手册.md`。
- 分类级模板覆写：`{include}` 前用 `mac_tpl_fetch($model,$tpl,$default)`（[app/common.php:2162](file:///D:/wwwroot/maccms/maccms12/app/common.php#L2162)）按后台分类设置选模板。
- 前台短语多语言：`{:mac_front_string('key','中文兜底')}`、`{:mac_tpl_text('中文')}`，见 `08-多语言手册.md` §5/§6。

## 8. 属性怎么查才算准

想知道某个属性到底生效不生效，只有一条可靠办法：**去对应模型的键提取段看它读不读**。

| 标签 | 键提取位置 |
|---|---|
| vod / art / manga | `app/common/model/{Vod,Art,Manga}.php` 的 `listCacheData()` 开头 |
| actor / role / website / topic | 同名模型 `listCacheData()` |
| type / link / comment / gbook | 同名模型 |
| area/lang/class/year/version/state/letter | `app/common/model/Extend.php`（白名单在 `:22-36`） |

后台还有一个「标签向导」页面（`admin.php/template/wizard`，[app/admin/controller/Template.php:231](file:///D:/wwwroot/maccms/maccms12/app/admin/controller/Template.php#L231)）可以边写边查语法。
