# 接口与采集手册

讲清 `/api.php` 上每一条对外 URL 的**形态、鉴权、参数、返回**，以及**采集**（取数据进来 / 把数据供出去）的两套协议。
结论按当前代码核对（2026-10-26）。文中只写配置**键名**，不写任何密钥值。

## 1. URL 形态

- 入口 [api.php:19-20](file:///D:/wwwroot/maccms/maccms12/api.php#L19) 绑定 `BIND_MODULE='api'`，[api.php:50-58](file:///D:/wwwroot/maccms/maccms12/api.php#L50) 把 `?s=` 兼容写法归一成 PATH_INFO。
- **没有路由表**：`route/` 目录只有 `addons.php`，`api` 模块下也没有 `route/rewrite.php`，所以接口走 ThinkPHP 默认的「控制器/方法」解析。
- 形态：`/api.php/{控制器}/{动作}[.html|.xml]?参数`。控制器名**大小写不敏感**（`Task` 与 `task` 等价），动作里的下划线保留。
  依据 [config/route.php:4-11](file:///D:/wwwroot/maccms/maccms12/config/route.php#L4)：`url_route_must=false`、`url_convert=true`、`url_html_suffix='html|htm|shtm|shtml|xml'`。
- 找不到控制器时落到空控制器 `MyError`（[config/route.php:9](file:///D:/wwwroot/maccms/maccms12/config/route.php#L9)），该类是**空类**。
- **全站没有 JSONP / callback 参数**（`grep -r "jsonp|callback" app/api` 零命中），也不做签名校验。

**P 的行为细节**（最容易踩）：
- `api.publicapi.status != 1` → 直接 `echo 'closed'; die;`，返回的是**纯文本 `closed`，不是 JSON**（[PublicApi.php:9-12](file:///D:/wwwroot/maccms/maccms12/app/api/controller/PublicApi.php#L9)）。
- `charge == 1` 时按 `api.publicapi.auth`（`#` 分隔的 IP 或域名，域名会 `gethostbyname`）比对客户端 IP，不匹配输出 `api/auth_err` 并 `exit`。
- **`127.0.0.1` 永远在白名单里**（[PublicApi.php:29](file:///D:/wwwroot/maccms/maccms12/app/api/controller/PublicApi.php#L29)）。本机自调一定能通，别拿它当「线上也放行」的证据。
- 客户端 IP 取 `mac_get_client_ip()`：多层代理后要配 `trusted_proxies`，否则白名单判的是代理 IP。

**JWT（L 的可选传输）**：总开关 `app.api_jwt_enabled`（默认 `'0'`），且 `app.api_jwt_secret` **长度 ≥32** 才真正启用
（[app/common/util/JwtService.php:8-16,51-61](file:///D:/wwwroot/maccms/maccms12/app/common/util/JwtService.php#L8)）。签发 `POST /api.php/auth/jwt`（[Auth.php:295-341](file:///D:/wwwroot/maccms/maccms12/app/api/controller/Auth.php#L295)，HS256），
`app.api_jwt_ttl` 默认 7200 秒，`app.api_jwt_iss` 默认 `maccms`。

**限流**：`PublicApi::apiRateLimit($action,$user_id,$limit,$window)` 按 **用户 + IP 两个桶**计数，命中返回 `code 1020`
（[PublicApi.php:55-88](file:///D:/wwwroot/maccms/maccms12/app/api/controller/PublicApi.php#L55)）；Redis 可用时用 `INCR`，否则退回缓存计数器。
另有反爬中间件（`app.anti_scrape_api_*` / `anti_scrape_index_*`）与 IP 封禁中间件，见 `09-安全与权限手册.md` §8。

## 4. 返回格式

### 4.1 读取类（P/L）

```json
{ "code": 1, "msg": "...", "info": { ... } }
```

- 列表分页：`info.offset` / `info.limit` / `info.total` / `info.rows`（[app/api/controller/Vod.php:108-117](file:///D:/wwwroot/maccms/maccms12/app/api/controller/Vod.php#L108)）。
- banner / hot / rank / latest 用 `info.total` + `info.rows`。
- 详情：`info` 就是那一行记录（[Vod.php:219-223](file:///D:/wwwroot/maccms/maccms12/app/api/controller/Vod.php#L219)）。
- 播放/下载：`info.play_list / current / sid / nid / play_url`（[Vod.php:681-696](file:///D:/wwwroot/maccms/maccms12/app/api/controller/Vod.php#L681)）。
  原始字段 `vod_play_url`、`vod_play_server`、`vod_play_note` 在详情里会被 `unset`（[Vod.php:205-206](file:///D:/wwwroot/maccms/maccms12/app/api/controller/Vod.php#L205)），只走 `get_play_info`。
- 字段裁剪：每个动作各自写死 `field` 白名单（[Vod.php:91,325,402,458,526](file:///D:/wwwroot/maccms/maccms12/app/api/controller/Vod.php#L91)）。图片统一走 [mac_url_img()](file:///D:/wwwroot/maccms/maccms12/app/common.php#L2178)，命中防盗链 key 时改写成 `/img.php?url=`。
- 编码 `JSON_UNESCAPED_UNICODE`。`code > 1` 表示失败（`error()` 出口）。
- **接口结果也有缓存**：如 `<flag>_api_vod_latest_by_type_*`（[Vod.php:446-452](file:///D:/wwwroot/maccms/maccms12/app/api/controller/Vod.php#L446)），受 `app.cache_core` 与 `app.cache_time` 控制。

- JSON：顶层 `code` / `list` + 分页 `page` / `pagecount` / `limit` / `total`，`list[]` 为记录，另带同级 `class[]` 字典（[Provide.php:234-249](file:///D:/wwwroot/maccms/maccms12/app/api/controller/Provide.php#L234)）。

## 9. 排障速查

| 症状 | 原因 | 处理 |
|---|---|---|
| 接口返回纯文本 `closed` | `api.publicapi.status != 1` | 后台「对接与账号/API」把开放接口打开 |
| 返回 `api/auth_err` | `charge=1` 且客户端 IP 不在 `api.publicapi.auth` | 补白名单；或核对 `trusted_proxies`（代理后 IP 取错） |
| 本机测试通、线上 403 | `127.0.0.1` 恒放行造成假象 | 用外网 IP 复测 |
| `receive/*` 一直失败 | `interface.status=0`，或 `pass` 长度 <16 | 开启并设 ≥16 位口令 |
| 采集 `code 9001` | `cjflag != md5(cjurl)` | 用 `cjurl` 的 md5 作 `cjflag` |
| 正文里的 `<script>` 变成 `*` | `mac_filter_tags()` 强制净化 | 预期行为，供数侧不可关闭 |
| 详情里拿不到 `vod_play_url` | 字段被 `unset` | 改用 `/api.php/vod/get_play_info` |
