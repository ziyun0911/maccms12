# 文档导航

这里是 maccms12（ThinkPHP 8 / PHP 8.3 版）**唯一的使用者文档入口**。

本期（2026-10-26 ~ 10-27）把原有文档全部按同一口径重写：

- **每一句都要能在当前代码树里核对**，凡引用代码处一律给 `文件:行`；
- **不写迁移流水账、不写与官方文档的逐条比对**——那些收进 [90-变更记录.md](file:///D:/wwwroot/maccms/maccms12/说明文档/90-变更记录.md)；
- 旧的 `.txt` 说明转成了 Markdown 手册，处置对照见 §4。

> 后台左侧「网站参数 → 说明文档」也能打开本目录（[Doc.php](file:///D:/wwwroot/maccms/maccms12/app/admin/controller/Doc.php)），
> 但那一页是 `<pre>` + `htmlspecialchars` 渲染（[view/doc/info.html:22](file:///D:/wwwroot/maccms/maccms12/app/admin/view/doc/info.html#L22)），
> **Markdown 语法会原样显示成源码**。本期刻意没有引入前端 Markdown 渲染器：后台这一页的定位是「应急看原文」，
> 加渲染器要引第三方库、要过 CSP、还要处理 `.htaccess` 与拦截清单，收益不抵成本。**要阅读体验请在 IDE 或 Git 平台里看这些 .md。**

## 6. 维护约定

1. **可核对性优先**：新增结论必须带 `文件:行`；写不出依据的句子就不要写。行号会漂，所以同时写清函数名/键名。
2. **知识点进文档，不进代码注释**：本仓库已全量剥离代码注释（见 90 §2 与项目约定），新学到的机制补进对应手册的相应小节。
3. **90 是唯一允许「过期」的文件**：它的 §2 是时间冻结的归档，不随代码更新；§1 台账在缺陷修掉后要**删除**对应行，而不是留着。
4. 手册之间**不重复机制细节**：配置项作用只在 02，菜单与操作只在 03，钩子/驱动只在 10，CSRF 与拦截只在 09；其他地方一律交叉引用。
5. 任何文档都不写密钥值——只写键名与去哪填（`api_jwt_secret`、`interface.pass`、`monitor.cron_token` 等同理）。
