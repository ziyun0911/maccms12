
========================================================================
maccms12（ThinkPHP 8）说明
========================================================================
本文档基于官方 maccms10「站外入库接口说明」整理。maccms12 站外入库接口
与 maccms10 完全一致：
· 后台「网站参数 → 内容接入 → 站外入库配置」设置免登录入库密码（interface.pass，>=16 位）
  与分类名称对应规则（interface.status=1 开启后生效）。
· 入库接口文件：http://域名/api.php（Receive 控制器）。
· 火车头配置：网站根地址填 http://域名/api.php/；测试时填验证密码。
· 本目录「火车头模块/」下为官方提供的采集/入库模块（.wpm），共 6 个：
  苹果CMS10.x视频 / 文章 / 明星（演员） / 角色 / 网址 / 评论（文件名带「10.x」是
  官方原始命名，maccms12 的入库接口与 maccms10 完全兼容，导入火车头后可直接用）。
  漫画没有对应 .wpm，需按 /api.php/receive/manga 自行对接。
· 入库接口地址（均需带 pass 参数；校验见 app/api/controller/Receive.php 同名方法）：
  视频   /api.php/receive/vod        必填 vod_name、type_id 或 type_name
  文章   /api.php/receive/art        必填 art_name、type_id 或 type_name
  演员   /api.php/receive/actor      必填 actor_name、actor_sex、type_id 或 type_name
  角色   /api.php/receive/role       必填 role_name、role_actor、vod_name 或 douban_id
                                    （角色不接分类，靠 vod_name/douban_id 挂靠到视频）
  网址   /api.php/receive/website    必填 website_name、type_id 或 type_name
  漫画   /api.php/receive/manga      必填 manga_name、type_id 或 type_name
  评论   /api.php/receive/comment    必填 comment_name、comment_content、comment_mid，
                                    以及 rel_name 或 douban_id（定位挂靠的内容）
  ※ type_name 走后台「站外入库配置」里的分类名称转换表（mac_interface_type()），
    与 type_id 同时存在时以 type_id 为准。
  ※ 评论入库是已实现的接口（写入 Collect::comment_data），不是预留桩。
  ※ 未实现的模块不要按上面样式猜地址：专题 /topic、直播 /live、分集剧情等在
    Receive 控制器里没有对应方法，请求只会落到默认输出，不会入库。
· 系统同时提供数据输出接口（供采集）：/api.php/provide/{vod|art|actor|role|
  website|manga|comment}/，详见《API接口说明.txt》正文三、与文末附录A。

========================================================================

站外入库接口一般是给第三方软件（如：火车头、ET等）提供的入库方案。

使用前请在后台系统-站外入库配置 设置好 免登录入库密码，和 分类名称对应系统分类规则。

系统默认api入库接口文件为http://域名/api.php，根据需要可修改入库文件。

下载官方提供的 苹果CMS-V10 火车头入库模块！
（模块文件就在本目录「火车头模块/」下，6 个 .wpm；名称里的「10.x」是官方原始
命名，maccms12 无需替换文件即可直接使用。）

火车头配置
   网站根地址填写 http://域名/api.php/

   点击测试，输入验证密码，填必要信息测试入库。
   （原文「何必要信息」是官方笔误，应为「填必要信息」。）

接口必要信息是：
   名称， 分类ID 或 分类名称 （如果同时存在以 分类ID为准）
   演员还要 性别（actor_sex）；角色不填分类，改填 演员名 + 所归属的视频名或豆瓣ID；
   评论填 评论内容 + comment_mid（模块编号）+ 所归属的视频名或豆瓣ID。
   各接口完整必填项见本文开头的清单。

入库接口地址
视频/api.php/receive/vod；
文章/api.php/receive/art；
演员/api.php/receive/actor；
角色/api.php/receive/role；
网址/api.php/receive/website；
漫画/api.php/receive/manga；
评论/api.php/receive/comment；

入库失败的返回码（JSON 的 code 字段）：
3001 站外入库开关未开启（interface.status≠1）
3002 入库密码错误
3003 入库密码长度不足 16 位（即使请求带对了密码也会被拒）
2001/2002/2003/2004 缺少对应接口的必填字段（各接口含义见 Receive.php）
