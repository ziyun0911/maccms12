# How to create articles and videos / 如何发布文章与视频

## A. 新建文章（手工）

**前提**：已在 **基础 → 分类列表**（`type/index`）里建好文章侧的 **一级类型** 与 **子分类** —— 分类页用 `type_mid` 区分归属模块（1 视频 / 2 文章 / 3 专题 / 8 演员 / 9 角色 / 10 剧情 / 11 网址 / 12 漫画，映射见 [app/common.php:1472-1489](file:///d:/wwwroot/maccms/maccms12/app/common.php#L1472-L1489)），内容分组下 **没有** 独立的「分类」菜单。

### 步骤

1. 登录后台 → 左侧 **文章**（图标或文字可能为「文章管理」）。  
2. 打开 **添加文章**（或 **文章 → 添加**）。  
3. 必填项通常为：**标题**，**归属分类**，**正文或简介**（以表单为准）。  
4. **封面图**：上传或填写图片地址；注意附件/远程图设置是否允许外链。  
5. **TAG / 关键词**：可选；利于前台检索与聚合。  
6. **发布状态 / 审核**：若站点要求审核，先保存为「未审核」，由有权限用户在 **文章 → 文章数据**（`art/data`）或 **未审核文章** 列表中批量或单条审核。  
7. 点击 **保存**。  
8. 前台打开 **文章分类页 / 详情页 URL**（取决于 **网站参数 → 网站参数** 的 **URL 地址配置** 区块与模板）核验展示。

### 文章采集入库

若文章来自采集：在 **采集** 中为文章节点配置好 **映射到本地文章分类**，执行采集后仍在 **文章 → 文章数据** 中检查、纠错、补图。

## B. 新建视频（手工）

**前提**：已在 **基础 → 分类列表** 建好视频侧类型/分类，并已准备 **播放器**（**视频 → 播放器**，`vodplayer/index`）。

### 步骤

1. 后台 **视频 → 添加**（或 **视频 → 添加视频**）。  
2. 填写 **标题、分类、封面、简介** 等基础信息。  
3. **播放地址**：存储约定是 `$$$` 分**线路**、`#` 分**集**、每集 `名称$地址[$播放器]`；表单里每条线路是一个多行文本框（**一行 = 一集**），保存时把换行归一成 `#`。粘贴时混入空行或多余分隔符会造成集数错乱 —— 完整格式见站内 **网站参数 → 说明文档 → 03-后台操作手册**。  
4. **播放组 / 线路 / 解析**：若使用多组播放，在表单对应区域添加；与 **播放器代码** 一致。  
5. **演员、导演、地区、年代、扩展分类**：按运营需要填写，影响前台筛选。  
6. **状态**：上架/推荐/审核 等按权限操作。  
7. **保存** → 前台 **视频详情页** 验证播放与清晰度。  

### 视频批量维护

在 **视频 → 视频数据** 使用筛选、批量改分类、批量删除；大批量前务必备份或使用「仅一批测试」策略。

### 剧情 / 分集（若启用）

- 后台有 **视频 → 有分集剧情** 列表入口（节点 `vod/data`，带剧情筛选参数）；用于维护 **连续剧分集文案或关联**。  
- **网站参数 → 网站参数** 的 **URL 地址配置** 区块里若有 **剧情** 路由开关，前台才有对应模板页；请以当前表单字段填写 **分集名称、内容与关联正片**。  
- 播放器、多集地址仍遵循 **播放器管理** 与 **`$$$` 分隔** 等约定（详见 **`13-player-server-downer.md`**）。

## C. URL 打不开或 404

1. **网站参数 → 网站参数 → URL 地址配置** Tab：确认各模块 `path[…]` 与 `rewrite[…]` 和服务器 PATHINFO / rewrite 一致。  
2. **Web 服务器**：Nginx / Apache **伪静态规则**需与官方示例一致（含 `try_files` / `RewriteRule`）。  
3. **分类是否隐藏、内容是否下架/未审核**。

## English summary

**Article**: Prepare **taxonomy** → **Article → Add** → fill title, category, body, thumb → save → verify front URL.  
**Video**: Prepare **taxonomy + player** → **Video → Add** → play URLs/lines → save → verify detail page playback.
